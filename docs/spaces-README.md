# Otonomaraç — Tek Kameradan Sürüş Algısı

Tek bir öne bakan kameradan sürüş sahnesini çözümleyen algı yığını:
tespit → takip → derinlik → kuşbakışı projeksiyon → çarpışmaya kalan süre,
üzerine sürülebilir alan segmentasyonu.

Ücretsiz CPU katmanında çalışır, gerçek zamanlı değildir: video yüklenir,
çevrimdışı işlenir, sonuç döner.

Kaynak kod ve mühendislik günlüğü:
[github.com/Byomer1021/otonomarac](https://github.com/Byomer1021/otonomarac)
